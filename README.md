# 📅 플랜더 (Plander) : Future Planning Calendar

## 🎀 프로젝트 소개

🏷 **프로젝트 명 : 플랜더(Plander) - 목표 관리 캘린더 앱 (캡스톤디자인)**

🗓️ **개발 기간 : 25.10.19 ~ 25.11.19**

👥 **TEAM 둘이둘희 : 박소희, 최서희**

---

### ✅ 기획 배경

> 기존의 할 일(To-do) 리스트는 단기적 관리에는 유용하지만, 최종 목표 도달에는 못 미치는 단점이 있다

- **문제 제기** : 할 일을 나열하는 방식만으로는 그 일들이 어떤 큰 목표로 이어지는지 파악하기 어렵다
- **핵심 기능** : 만다라트 차트로 목표를 세분화하고, 각각의 실천 계획을 시각적인 구슬과 캘린더를 통해 관리한다
- **최종 목표** : 자신의 노력이 쌓여가는 과정을 직관적으로 경험하여, 목표를 향한 꾸준한 실천을 습관으로 만들도록 돕는다

### ✅ 서비스 소개

> **만다라트 기법으로 목표를 세우고, 구슬뷰·캘린더로 실천을 관리하는 자기계발 앱**

- 핵심 목표 1개를 8개 세부 목표로, 다시 실천 계획으로 확장하는 만다라트 로직
- 목표를 습관형(매일/주 5회/주 3회/직접 입력)·달성형으로 설정해 관리
- 진행 중인 목표를 시각적 구슬로 표현하는 구슬뷰
- 캘린더 연동으로 목표 달성 여부·디데이·메모를 한 화면에서 확인

### 👥 서비스 대상

- 목표를 세워도 무엇부터 실천할지 막막한 사람들
- 노력이 쌓이는 과정을 시각적으로 확인하며 동기부여받고 싶은 사람들

## 🆚 유사 앱과의 비교

| 비교 앱 | 한계 | Plander의 개선점 |
| --- | --- | --- |
| 원모어(ONEMORE) - 할 일 Todo 목표관리 | 매일/매주/매달 목표를 세우고 캘린더로 일정 확인은 가능하나, 이루고자 하는 전체적인 목표 설계가 어려움 | **만다라트** 작성으로 한 해의 큰 목표를 잡고 세부 목표 작성이 쉬움 |
| 행복저금통 | 매일의 행복을 쪽지 형태로 저장해 개봉 날짜에 확인하지만, 단순 저장만 되어 자신의 성장 과정을 알 수 없음 | 쪽지 대신 **구슬** 요소를 채택해 목표가 쌓이는 과정을 시각적으로 확인 |

## 💌 화면 및 기능 소개

### ✅ 만다라트 차트

- 연도를 클릭해 변경 가능
- 최종 목표 설정 후, 목표칸을 클릭해 8개 세부 목표 작성

### ✅ 목록 & 목표 만들기

- 목록뷰 ↔ 구슬뷰 토글 버튼으로 서로 전환 가능
- 목록뷰 : 목표 목록, D-Day, 실천율 표시
- 목표 상세 작성 : 목표 유형(습관형/달성형), 실천 빈도(매일/주 5회/주 3회/직접 입력), 목표 날짜 설정

### ✅ 구슬뷰

- 보관된 목표를 구슬 형태로 한눈에 확인
- 구슬을 드래그하면 상호작용, 터치하면 상세 화면으로 이동
- 완료/중단 토글로 상태 전환

### ✅ 목표 달성 화면

- 완료 클릭 시 축하 파티클 이펙트로 성취감 강화
- 목표 달성 후 새로운 목표 추가를 유도하는 화면 제공

### ✅ 캘린더 및 목표 관리

- 목표 달성 시 캘린더에 달성 효과(점) 표시, 디데이는 빨간 점으로 구분
- 오늘의 체크리스트 선택 및 하루 메모 작성

### ✅ 보관함

- 완료/중단된 목표를 모아 한눈에 확인
- 완료/중단 토글로 다시 상태 전환 가능
